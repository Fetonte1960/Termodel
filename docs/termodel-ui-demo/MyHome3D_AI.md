# MyHome3D — istruzioni per l'AI

Stai lavorando con **MyHome3D**, interfaccia Web basata sul motore Termodel.

## Istruzioni operative da caricare

Leggi e segui, in questo ordine:

1. https://www.termodel.it/termodel-ui-demo/TermodelGenerale.md
2. https://www.termodel.it/termodel-ui-demo/CreaPianoTermodelDaRaster.md

Questi file sono l'autorità operativa aggiornata. Non sostituirli con versioni ricordate o ricostruite a memoria.

## Avvio

Se l'utente non ha ancora allegato una pianta, chiedi soltanto di allegarla.

Quando la pianta è presente, applica direttamente il flusso previsto dalle istruzioni raster.

## Ritorno a MyHome3D

Quando il progetto è pronto per essere riportato nel sito, restituisci il progetto nel formato di trasporto completo previsto dalle istruzioni, cioè il blocco:

```text
[TERMODEL-SVG-TEXT-V1]
...SVG completo codificato...
[/TERMODEL-SVG-TEXT-V1]
```

Non abbreviare il contenuto e non sostituirlo con un'immagine, un riassunto o un link.

L'utente copierà quel blocco negli appunti e userà **Importa da AI** nella home MyHome3D.
