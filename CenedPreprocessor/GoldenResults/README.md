# Golden Results

Risultati di riferimento approvati per i casi prova.

Un Golden Result deve indicare almeno:
- identificativo del caso;
- versione della specifica;
- versione del preprocessore che lo ha prodotto o validato;
- input esatto;
- output atteso;
- eventuali tolleranze;
- data e motivazione dell'approvazione.

Non sostituire un Golden Result senza registrarne la ragione nello storico decisioni/commissioni.
