# Desktop

Versione desktop del preprocessore Cened destinata al percorso reale di certificazione.

Requisiti architetturali iniziali:
- comportamento deterministico e riproducibile;
- input/output tracciabili;
- versione visibile in caption;
- testabile senza dipendere dalla UI;
- implementazione fedele alla specifica comune;
- possibilità di produrre un pacchetto/build identificabile in modo univoco.

La tecnologia definitiva dell'interfaccia e del runtime verrà consolidata con una commissione dedicata.
