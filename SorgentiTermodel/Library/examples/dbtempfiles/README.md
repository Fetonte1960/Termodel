# Campione dbtempfiles

Questi sei file sono copie non modificate di un progetto sintetico di test denominato `hello`, proveniente da `artifacts/hello-climate-precheck-r1/project/hello/dbtempfiles`.

Servono esclusivamente a mostrare la serializzazione XML effettiva degli archivi desktop:

- `Pareti.xml`;
- `Finestre.xml`;
- `Confini.xml`;
- `Zone.xml`;
- `Ponti.xml`;
- `Piani.xml`.

Non sono una banca dati normativa, non definiscono lo schema e non devono essere assunti come valori predefiniti. Lo schema autorevole è `../../definizionedati/definizionedati.json`.
