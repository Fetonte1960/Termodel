# Library

Area di riferimento dei sorgenti Termodel condivisi con GPT.

Regola operativa: GPT puo leggere questi file per comprendere architettura, dipendenze e API, ma non deve modificarli salvo richiesta esplicita.

La provenienza e le impronte delle copie Desktop aggiunte per XML APE e pannelli
radianti sono registrate in `RIFERIMENTI-DESKTOP-APE-PANNELLI.md`.

La cartella `SorgentiPascal` contiene l'appendice storica per carichi termici,
canali, tubazioni, biblioteche DXF, definizioni `base.dat` e relativi programmi
di gestione. È una copia consultiva derivata da materiale locale: per verificarla
o aggiornarla usare esclusivamente gli strumenti documentati in
`tools/pascal-library/README.md`.
